# CLI telemetry

Node24.14+, pnpm10.33.2. `corepack pnpm install`, copy `.env.example` to `.env.local`, set the existing Amplitude test key. Run `corepack pnpm test`, then `corepack pnpm demo sample.txt`. The CLI counts lines locally, then flushes a fixed outcome event and inspects its per-event result. A telemetry failure preserves the command exit code. DO_NOT_TRACK=1, --no-telemetry and a blank key skip SDK import/init and identity storage. Opt-out prevents new collection; it does not remove previously stored identity or sent data. The enabled identity is an anonymous UUID persisted in the configured local directory, not a login/account identity. No path, file text, arguments or raw errors are sent. Node's scheduled queue timer may keep the process for up to the configured one-second interval after flush. No forced process.exit, hosted service or third-party signup.
