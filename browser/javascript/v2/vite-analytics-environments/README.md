# Vite analytics environments

Node22.12+, pnpm10.33.2. `corepack pnpm install`, `corepack pnpm test`. Copy .env.example to .env.development.local, .env.staging.local and .env.production.local. Use plain unquoted values. Set APP_ENV/marker for each corresponding mode and supply three distinct designated ingestion keys/project IDs. Do not use .env.local for these keys. `corepack pnpm check:env` verifies local configuration distinctness; `corepack pnpm build` builds all three output directories. Serve each with `corepack pnpm preview --outDir dist/development` (or staging/production). Use only test destinations for initial verification; production mode is a build mode, not authorization to send fixtures to a real production project.

VITE_ values are public at build time. NODE_ENV is not a replacement for Vite mode: staging builds can still be optimized production builds. Rebuild when changing a key; Vite preview serves compiled assets. Labels/project IDs are human configuration, not server proof that an API key belongs to that project. Compare actual processed marker in each designated project and verify absence in the other two. Local tests/builds can prove wiring but not live project isolation. Author verification currently awaits two additional designated test projects; no cross-project live claim yet.
